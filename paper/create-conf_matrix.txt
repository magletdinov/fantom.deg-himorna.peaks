# Тест Фишера.
Для того чтобы подвердить значимые корреляции для пар (lncRNA,геномная модицификация)....
Нами была выдвинута следующая нулевая гипотеза: "Нет никаких неслучайных ассоциаций между двумя категориальными переменными (гены, ассоциированные с данной lncRNA для данной геномной модификации и дифференциально экспрессируемые гены при нокдауне данной lncRNA при данной aso)".
Для проверки данных гипотез мы использовали двусторонний точный тест Фишера. Гипотезы были разбиты на частные случаи в сочетаниях: up/down-экспрессия и plus/minus-корреляция ассоциированности.
## Создание матриц неточностей.
Для создания матриц неточностей 2*2 нами была реализована следующая схема анализа: для каждой матрицы были рассчитаны значения TP, TN, FP и FN следующим образом: для вычисления каждого из них были получены булевые маски над всем множеством генов из разметки l2 в np.array виде, это позволило быстро проводить операции переcечения и объединения:
        TP = len(deg_mask & corr_mask)
        TN = len(deg_mask & ~corr_mask)
        FP = len(~deg_mask & corr_mask)
        FN = len(~(deg_mask | corr_mask))
Вычисления были распараллелены по различным геномным модификациям и экспериментов с нокдауном.

Так, для каждого эксперимента по нокдауну (ips и fibroblast) было получено значение p-value для каждой уникальной 5ки переменных:
(геномная модификация, lncRNA, aso, знак корреляции, знак экспрессии).
Поправка на множественное тестирования была проведена для данного эксперимента в рамках одной геномной модификации. Порог на p-value был выбран 0.05.

В дальнейший анализ были отобраны только те lncRNA и геномные модификации, у которых хотя бы в одном из типов регуляции (нужно рассказать про это выше, когда разбиваем на up/down и +/- корреляции) была замечена значимая связь.
